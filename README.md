# Sizani-Youth-Foundation-current

Sizani Youth Foundation Website
About The Project

This project is a website for Sizani Youth Foundation, a non-profit organisation based in Soweto.

The foundation helps young people through tutoring, mentorship and digital literacy programmes.

The purpose of the website is to give the foundation an online presence and make it easier for people to find information about the organisation.

What Does The Website Do?

The website allows users to:

Learn more about Sizani Youth Foundation.
View the different programmes.
Learn about the foundation's impact.
Find information about volunteering.
Find donation information.
Read news and learner success stories.
Find the foundation's contact information.
